## 1. Purpose

This contract defines the minimal SELFCOMMUNICATION invariant set that a
CodingSELF must encounter at repository boot before it interprets the repository
as an ordinary software project.

The contract is not a doctrine dump. It is a source for compact endpoint boot
projections:

```text
ONE_COMMUNICATION_CONSTITUTION
-> AGENTS.md for CodexSELF
-> CLAUDE.md for ClaudeSELF
-> future endpoint adapters
```

## 2. Layer Separation

```text
AGENTS.md = BOOT_POINTER_PLUS_NON_COLLAPSE_LAWS
CLAUDE.md = BOOT_POINTER_PLUS_NON_COLLAPSE_LAWS_FOR_CLAUDESELF
SELFCOMMUNICATION_DOCTRINE = SEMANTIC_SOURCE
INSELFACTION = LIVING_ACTION_RECORD
```

The boot files orient an arriving agent. They do not replace doctrine, archive
history, or event validation.
